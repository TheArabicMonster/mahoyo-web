# Dictionnaire d'interface (FR / JA / EN)

Issue #184 (WEB-05). Tous les libellés de l'interface passent par `src/ui/i18n.ts`. Les textes sont ceux de notre projet, jamais des textes du jeu d'origine.

## Fichiers

| Fichier | Rôle |
|---|---|
| `src/ui/i18n.ts` | API : `t`, `translate`, `setUiLanguage`, `getUiLanguage`, `onUiLanguageChange`, `uiLocale`, `createI18n`. Aucun accès au DOM, aucune dépendance externe. |
| `src/ui/locales/fr.ts` | Français : **langue de référence**. Ses clés définissent le type `MessageKey`. |
| `src/ui/locales/ja.ts`, `en.ts` | Typés `Record<MessageKey, string>` : une clé manquante ou en trop fait échouer `tsc`. |
| `tests/unit/ui/i18n.test.ts` | Complétude, paramètres, repli, clés décoratives, garde-fou « pas de libellé en dur ». |

## Utiliser un libellé

```ts
import { t } from "@/ui/i18n.js";

button.textContent = t("pause.resume");
toast(t("toast.scriptNotFound", { file })); // paramètres typés : { file } est exigé
```

- `t(clé, params?)` lit la langue courante. Une valeur absente d'une langue retombe sur le français, puis sur la clé elle-même (jamais d'exception).
- `translate(langue, clé, params?)` vise une langue précise sans changer la langue courante.
- Les paramètres s'écrivent `{nom}` dans le texte. Le typage exige exactement ceux du texte français.
- Format de date ou de nombre : `uiLocale()` (`fr-FR`, `ja-JP`, `en-US`).
- Les noms de langue (`日本語`, `English`, `Français`) ne se traduisent pas : `LANGUAGE_NAMES`.

## Ajouter une clé

1. Ajouter `"écran.élément": "Texte"` dans `src/ui/locales/fr.ts`, dans le groupe de l'écran (commentaire `// ── Écran ──`). Convention : `écran.élément` en camelCase, paramètres `{nom}`.
2. Ajouter la même clé, avec les mêmes `{paramètres}`, dans `ja.ts` et `en.ts`.
3. Utiliser `t("écran.élément")` dans le code. `npx tsc --noEmit -p .` et `npm run test:unit` échouent si une langue est incomplète ou si un paramètre diffère.

Ne pas ajouter de libellé en dur dans `src/ui/ui-manager.ts` : un test le détecte (lettre accentuée ou japonaise dans un littéral). Pour un nouveau module d'écran (`src/ui/<composant>.ts`), passer aussi par `t`.

## Sous-titres décoratifs (japonais d'un écran en français)

Les sous-titres japonais décoratifs de l'original sont `aria-hidden` (docs/ANALYSE_HUD_ORIGINAL.md, §10). Ils ont une **clé séparée** qui se termine par `.deco` :

```ts
import { decoKeyOf, t } from "@/ui/i18n.js";

title.textContent = t("title.entry.config");
subtitle.textContent = t(decoKeyOf("title.entry.config")); // "title.entry.config.deco"
subtitle.setAttribute("aria-hidden", "true");
```

Une clé `.deco` doit exister dans les trois langues comme les autres (le test de complétude s'applique). `isDecorativeKey(clé)` permet de les filtrer.

## Langue de l'interface

- La langue de l'interface est le réglage « Langue » du joueur (`GameSettings.language`), comme le texte du jeu.
- Le player appelle `setUiLanguage` au chargement des réglages et quand le joueur change de langue. Il transmet la langue **demandée**, même si la traduction du texte n'est pas installée (le texte retombe alors sur le japonais, pas l'interface).
- `DomUIManager` écoute `onUiLanguageChange` : il pose `lang` sur `#ui-overlay` et sur `document.documentElement`, puis redessine l'écran courant.
- Le français est la langue par défaut (`FALLBACK_LANGUAGE`).

## Entrées du titre d'origine

`title.entry.start|load|config|extra` valent *Start / Load / Config / Extra* en français comme en anglais (l'original les garde en anglais même dans le patch FR, docs/ANALYSE_HUD_ORIGINAL.md §2.1). Elles sont réservées à l'écran titre refait (HUD-07, #195) ; l'écran actuel utilise encore `title.newGame`, `title.load`, etc.

## Limites connues

- `formatBinding` (`src/core/shortcuts.ts`) écrit « Espace » en dur pour la touche espace.
- Les libellés de `SHORTCUT_DEFINITIONS` et `WINDOW_SIZE_OPTIONS` restent dans `src/core` comme valeurs de repli ; l'interface lit `shortcut.<id>` et `config.screen.windowSizeFit`, et un test vérifie qu'ils restent alignés sur le français.
- Les libellés des chapitres (`ScriptSummary.label`) et le texte des sauvegardes viennent des données, pas du dictionnaire.
